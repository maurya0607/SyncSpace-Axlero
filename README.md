# SyncSpace

## Project

SyncSpace is a real-time collaborative platform that combines a shared whiteboard and code editor, allowing multiple users to collaborate in real time. The project enables users to create or join rooms, communicate through a shared workspace, and work together efficiently.

## Branch Workflow

- Every team member works on their own feature branch.
- Push code regularly to the assigned feature branch.
- Create a Pull Request to the `develop` branch after completing the assigned task.
- The Team Lead reviews and merges Pull Requests into the `develop` branch.
- The `main` branch is reserved for the final stable version.
