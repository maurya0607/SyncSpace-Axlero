1. Executive Summary

SyncSpace is a real-time collaborative web application developed as part of the Axlero Internship Program. The platform empowers distributed development teams to brainstorm on an interactive whiteboard and edit multi-file code simultaneously in real time. The project is fully completed and in production, with the frontend deployed on Vercel and the backend on Render.

4. Objectives

  1. Build a real-time collaborative code editor with multi-file support and active tab syncing.
  2. Implement a shared whiteboard with canvas-based multi-user drawing synchronization.
  3. Develop secure user authentication using JWT and bcrypt password hashing.
  4. Enable room-based collaboration with invite validation.
  5. Persist collaborative state (code and binary Yjs document state) to MongoDB Atlas.
  6. Deploy the full-stack system to production (Vercel + Render).
  7. Provide dedicated code execution capability within the workspace editor.

7. Features Implemented

1. User Authentication

Secure registration and login with bcrypt password hashing and JWT token issuance. Supports 'Remember Me' (localStorage vs sessionStorage) and route protection.

2. Room Management

Creation of rooms with unique IDs, user invitation mechanism, and live membership verification for every connection attempt.

3. Collaborative Code Editor

Multi-file support (create, switch, delete files), real-time synchronized editing powered by Yjs CRDTs, and active file tab synchronization.

4. Shared Whiteboard

Interactive HTML5 canvas whiteboard supporting simultaneous drawing, stroke synchronization, and shape coordination via Socket.IO events.

5. Code Execution Engine

Integrated /api/execute endpoint allowing developers to run code snippets directly from the editor interface.

6. Real-time Presence & Cursor Awareness

Live active user roster and remote cursor broadcasting via awareness update events.

7. Reliable MongoDB Persistence

5-second debounced background timer that flushes in-memory Yjs binary state buffers and code content to MongoDB Atlas.
